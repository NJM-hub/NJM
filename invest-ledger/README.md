# 투자수익 장부 관리 프로그램

투자 실행금액과 약정 수익률로 **총 회수예정금액·회수 스케줄을 자동 생성**하고, 실제 입금을 기록하면 잔액·미수·지연·연체·만료 상태가 즉시 다시 계산되는 웹 장부입니다. PC와 휴대폰(반응형)에서 사용할 수 있습니다.

- 기술 스택: Node.js 22.5+ · Express · SQLite(`node:sqlite`, 별도 DB 서버 불필요) · Chart.js · ExcelJS
- 데이터 파일: `data/ledger.db`, 자동 백업: `data/backups/`

## 실행

```bash
cd invest-ledger
npm install
npm run seed     # (선택) 샘플 데이터 19건 생성. 기존 투자 데이터는 지워짐, 계정은 유지
npm start        # http://localhost:3100
```

처음 접속하면 **관리자 계정 만들기** 화면이 나옵니다. 같은 와이파이의 휴대폰에서는 `http://<PC의 IP>:3100`으로 접속합니다.

| 환경변수 | 설명 |
|---|---|
| `PORT` | 포트 (기본 3100) |
| `LEDGER_DATA_DIR` | DB·백업 폴더 (기본 `./data`) |
| `COOKIE_SECURE=1` | HTTPS로 서비스할 때 설정 (세션 쿠키 Secure) |
| `TRUST_PROXY=1` | 리버스 프록시 뒤에서 실행할 때 설정 |

인터넷에 공개할 때는 반드시 HTTPS(리버스 프록시 등) 뒤에서 `COOKIE_SECURE=1`로 실행하세요. SQLite 파일을 쓰므로 Vercel 같은 서버리스가 아닌, 디스크가 유지되는 서버(VPS, Railway, Fly.io 볼륨 등)에 배포합니다.

## 주요 기능

| 화면 | 기능 |
|---|---|
| 대시보드 | 총 실행/회수예정/회수/미회수/예상수익, 오늘·이번 달 현황, 연체·일부입금·지연·만료임박·정상 건수, 앞으로 받을 돈(7/30/60일·이번 주·이번 달·다음 달), 월별 그래프·회수율 원형 그래프 |
| 날짜별 회수현황 | 특정 날짜의 회수 예정·실제 회수·미회수·연체 포함 미수금, 당일 예정 목록·이전 미수 목록·당일 입금 기록 |
| 투자 목록 | 고객명·투자처명·투자번호 검색, 필터(전체/진행중/정상/일부입금/미입금/연체/만료임박/완납) |
| 투자 등록 | 기간(일·**주**·개월 프리셋 + 직접 입력), 회수주기(매일·7일·10일·15일·매주·2주·매월 + 직접 설정), 회수방식, 실시간 계산 미리보기 |
| 투자 상세 | **생애주기**(실행금액 → 약정수익 → 총 회수예정 → 스케줄 → 실제 입금 → 지연 → 잔액 → 완납), 기간 경과/회수 진행 바, 회차별 스케줄, 전액·부분 입금, 선택 회차 일괄 입금, 일괄(회차 미지정) 입금, 예정액 수정, 입금 기록 수정/삭제, 수정 이력 |
| 회수 캘린더 | 월 달력에 날짜별 예정액·입금·미수, 날짜 클릭 시 해당일 투자건 목록 |
| 고객 / 투자처 | 고객·투자처별 합계와 투자내역, 정보 수정 |
| 월별 통계 | 월별 실행금액·건수, 월별 예정/실제/미회수, 그래프 |
| 엑셀 | 전체 투자목록·고객별·월별 실행·월별 회수·회수 스케줄·연체 목록 다운로드, 기존 장부 업로드(양식 제공, 미리보기 후 가져오기) |
| 설정·보안 | 연체 기준일, 비밀번호 변경, 계정 추가/삭제, DB 백업·내려받기, 전체 수정 이력 |

상단의 **오늘 / 특정 날짜** 전환으로 모든 화면을 원하는 날짜 기준으로 다시 계산할 수 있습니다. 특정 날짜 기준에서는 그 날짜까지의 입금만 반영됩니다.

## 계산 규칙

- 모든 금액은 **원 단위 정수**. 수익 = 실행금액 × 수익률(소수 4자리까지)을 BigInt로 계산 후 원 단위 반올림.
- 균등분할의 나머지(1~몇 원)는 **마지막 회차에서 자동 조정** → 회차 합계가 총 회수예정금액과 항상 정확히 일치.
- 회수 기간은 첫 회수일(기본 = 실행일)부터 `기간`만큼. 예) 9/1 실행, 100일 매일 → 9/1~12/9 100회, 만료일 12/9.
  - 주 단위 기간: `N주 = N×7일`. 예) 12주 매주 → 12회, 8주 2주마다 → 4회.
  - 개월 단위: 같은 날짜로 증가, 말일 보정(1/31 → 2/28).
- 회수방식 (`src/schedule.js`의 `METHODS`에 항목을 추가하면 새 방식 확장 가능)
  - 원금+수익 균등회수 / 원금 균등회수(수익은 남은 원금 비례 체감) / 수익 균등회수(원금 만기) / 만기 일시상환 / 직접 회수금액 입력
- 입금 배분: 회차를 지정한 입금은 그 회차에 먼저, 회차 미지정 입금과 초과분은 가장 오래된 미수 회차부터 충당.
- 회차 상태: 완료 · 예정 · 오늘 · 일부입금 · 지연(예정일 경과, 연체 기준일 이내) · 연체(기준일 초과, 기본 7일)
- 투자 상태: 완납(파랑) > 연체(빨강, 만료 경과 포함) > 일부입금(주황) > 지연(노랑) > 정상(초록)
- 만료 표시: 30일 이상 정상 · 15~30일 주의 · 7~15일 임박 · 7일 이내 긴급 · 경과 시 만료경과

## 보안

- 로그인 필수, 비밀번호 scrypt 암호화, HttpOnly·SameSite 세션 쿠키(12시간, 사용 중 자동 연장)
- 로그인 시도 제한(IP당 10분 10회), 상태 변경 요청 CSRF 헤더 검사, CSP 등 보안 헤더
- 삭제 전 확인창, 투자건은 소프트 삭제
- 투자 조건·입금액·회차 금액 등 모든 변경을 **수정 이력**(변경 전 → 후)으로 기록
- 시작 시·매일·엑셀 업로드 전 자동 백업(최근 30개), 설정 화면에서 백업 파일 내려받기

복원: 서버를 멈추고 `data/ledger.db`를 백업 파일로 교체한 뒤 다시 시작합니다.
