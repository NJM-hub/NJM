## 공통 규칙

- 플랫폼마다 새로 쓴다. 같은 글을 번역·복사해 여러 곳에 올리지 않는다.
- 링크는 글당 1~2개. 첫 링크는 본문 문맥 안에, 두 번째는 끝에 브랜드 또는 URL 앵커로.
- 소셜(LinkedIn, Facebook, Pinterest) 링크에는 UTM을 붙여 유입을 구분한다: `?utm_source={플랫폼}&utm_medium=social&utm_campaign=backlink`. 블로그형(Medium, Tumblr, Blogger, PIXNET, note, Hatena)은 깨끗한 URL을 쓴다.
- 이미지는 사용자가 가진 실제 차량·여행 사진만. 이미지가 없으면 "이미지 제안"만 적는다.
- 글쓴이 표기: 골든카 공식 계정 또는 골든카 운영 여행 정보 블로그. 고객 후기 형식 금지.

## 플랫폼별 규칙

### LIN — LinkedIn
- 대상: 출장자, 여행사·MICE 담당자, 기업 의전 담당
- 형식: 회사 페이지 게시물. 첫 두 줄에 핵심(접혀서 "더보기" 전에 보이는 부분)
- 길이: 800~1,500자. 짧은 문단, 줄바꿈 많이
- 주제: 출장자 공항 이동 팁, 단체 이동 계획, 한국 공항 이동 선택지 비교, 기업 의전 체크리스트
- 링크: 본문 끝 1개 (UTM). 외부 링크가 노출을 줄이는지는 검증 필요 — 첫 댓글에 넣는 방식과 비교 기록
- 해시태그: 3~5개 (#KoreaTravel #BusinessTravel #IncheonAirport 등)

### MED — Medium
- 대상: 여행 계획 중인 개인, 정보 검색 유입
- 형식: 가이드형 글. 제목 + 부제 + 소제목(H2) 3~5개
- 길이: 영어 800~1,500단어 / CJK 2,000~3,500자
- 주제: "인천공항에서 서울 가는 방법 비교", "아이와 짐 많을 때 공항 이동", "서울 근교 하루 코스" 등 정보 우선, 골든카는 선택지 중 하나로 소개
- 링크: 본문 중 1개 + 끝 1개
- 태그: 최대 5개 (Korea Travel, Seoul, Incheon Airport, Travel Tips, 언어별 태그)
- 추가 칸: 부제(140자 안팎)

### FB — Facebook 페이지
- 대상: 해당 국가 팔로워, 공유 유입
- 형식: 짧은 게시물 + 링크 미리보기 카드
- 길이: 300~700자. 첫 문장에 질문이나 상황 제시
- 주제: 시즌 팁(눈·연휴·항공 지연), 공항 이동 Q&A, 투어 코스 하나 소개
- 링크: 1개 (UTM). 미리보기 카드 제목·이미지가 언어에 맞게 나오는지 게시 후 확인
- 해시태그: 2~4개
- 그룹 게시: 그룹 규칙에서 홍보 허용 확인 전에는 금지

### TUM — Tumblr
- 대상: 여행 이미지·짧은 글 탐색 사용자
- 형식: 사진 게시물 또는 짧은 텍스트
- 길이: 영어 150~400단어 / 일본어 400~1,000자
- 링크: 1개
- 태그: 5~10개. 검색에 반영되는 태그 개수 제한이 있다는 정보가 있어 가장 중요한 태그를 앞에 둔다 (개수 기준은 검증 필요)

### BLG — Blogger
- 형식: 블로그 글. 언어별로 블로그 분리 권장 (예: 繁中 블로그, English 블로그)
- 길이: Medium과 비슷하되 주제·구성을 다르게
- 추가 칸: 검색 설명(150자 안팎), 라벨 3~5개
- 링크: 본문 1개 + 끝 1개

### PIN — Pinterest
- 형식: 세로 이미지 핀 + 목적지 링크
- 제목 100자 이내, 설명 500자 이내 (공식 기준, 검증일 기록 필요)
- 이미지: 세로 2:3 비율 권장. 실제 사진이 없으면 게시 보류
- 링크: 목적지 URL 1개 (UTM)

### PIX — PIXNET 痞客邦
- 언어: 대만 번체, 대만식 표현(保母車, 九人座, 接送)
- 형식: 여행 정보 글, 사진 여러 장, 소제목
- 길이: 1,500~3,000자
- 링크: 본문 1개 + 끝 1개

### NOTE — note / HTN — Hatena Blog
- 언어: 자연스러운 일본어, です・ます체
- 형식: 체험·준비 가이드형. 표나 체크리스트 활용
- 길이: 2,000~4,000자
- 태그(note 해시태그 / Hatena 카테고리): 3~5개
- 링크: 본문 1개 + 끝 1개
