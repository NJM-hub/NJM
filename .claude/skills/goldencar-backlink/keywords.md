# 언어별 핵심 키워드 사전

해당 국가 사람이 한국에 왔을 때(또는 오기 전) 실제로 칠 만한 현지어 검색어를 모았다.
표기 변형, 띄어쓰기 변형, 옛 표기, 흔한 오타, 질문형 검색까지 포함한다.

- 검색량은 확인되지 않은 후보다. 서치콘솔 검색어 데이터가 쌓이면 실제 유입 검색어로 교체·추가한다.
- `presets.md`의 키워드는 이 사전의 ★ 핵심 키워드에서 고른 것이다.

## 사용 규칙

| 표시 | 뜻 | 어디에 쓰나 |
|---|---|---|
| ★ | 핵심 키워드 | 제목·본문·태그 |
| ○ | 자연스러운 변형·유사어 | 본문에 자연스럽게 섞어 쓰기, 태그 |
| ? | 질문형 검색 | 글 제목·소제목의 주제로 활용 ("~어떻게 가나요" 형식 글) |
| △ | 오타·옛 표기·잘못된 표기 (추정 포함) | **글에 쓰지 않는다.** 검색 의도 이해용. 서치콘솔 검색어 확인 시 참고 |
| ※ | 사실 미확인 서비스와 연결됨 | `facts.md`에서 확인되기 전까지 글에 쓰지 않는다 |

오타(△)를 제목·본문·태그에 일부러 넣지 않는다. 스팸으로 보이고 브랜드 신뢰를 떨어뜨린다.
같은 뜻이면 한 글 안에서 ★ 하나를 중심으로, ○ 1~2개만 자연스럽게 섞는다.

랜딩: `→a` = `/{locale}/airport`, `→t` = `/tour`, `→p` = `/protocol`, `→r` = `/rentcar`
