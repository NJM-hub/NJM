# 임대관리 ERP (rental-erp)

여러 임대 부동산의 **호실·임차인·계약·보증금·월세·관리비·미납·대출·이자·비용·수익률·현금흐름**을 한 곳에서 관리하는 임대사업용 ERP + 수익분석 시스템입니다. PC와 휴대폰에서 모두 쓸 수 있습니다.

- 기술: Next.js 16 (TypeScript) · PostgreSQL (Supabase) · Vercel 배포 · Claude API (계약서 AI 인식·AI 질문)
- 설계 문서 (화면 구성·DB 구조·계산식): [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)

## 주요 기능

| 메뉴 | 기능 |

| ✨ AI 질문 | "수익이 가장 좋은 건물?", "이번 달 미납금?", "3개월 안에 끝나는 계약?", "월세 5% 올리면?" 등 |

## 처음 설치하기 (Vercel + Supabase, 약 10분)

1. <https://vercel.com/new> → 저장소 **NJM** **[Import]**
2. **Root Directory** 를 `rental-erp` 로 지정 (중요: 비워 두면 다른 앱이 배포됩니다)
3. **Environment Variables**
   | Key | Value |
   |---|---|
   | `SETUP_PASSWORD` | 내가 정한 설치 비밀번호 (처음 관리자 만들 때 본인 확인용) |
   | `ANTHROPIC_API_KEY` | (선택) 계약서 AI 인식·AI 질문용 키 — <https://console.anthropic.com> |
   | `CRON_SECRET` | (선택) 아무 긴 문자열. 매일 아침 자동 청구·알림 |
4. **[Deploy]** (DB 가 아직 없어 첫 화면에 안내가 나와도 정상)
5. 프로젝트 **Storage** 탭 → **Create Database → Supabase** (Region **Seoul**) → **Connect** — DB 주소가 자동으로 들어갑니다
6. **Deployments → ⋯ → Redeploy** — 이때 DB 표가 자동으로 만들어집니다 (`scripts/migrate.mjs`)
7. 사이트 접속 → **처음 설정**에서 설치 비밀번호 + 관리자 이름·이메일·비밀번호 입력
8. **설정 → 데이터 → 샘플 데이터 넣기** 로 둘러본 뒤, 실제 사용 전에 **모든 임대 데이터 삭제**

> Supabase 를 직접 만든 경우: Supabase → Project Settings → Database → Connection string(**Transaction pooler**) 을 `DATABASE_URL` 에 넣고, SQL Editor 에서 `db/migrations/0001_init.sql` 을 한 번 실행하세요.

### 기존 엑셀 자료 옮기기

**통계/리포트 → 엑셀** 에서 양식(내보내기 파일)을 받아 같은 머리글로 채운 뒤, ① 부동산·호실 → ② 임차인 → ③ 계약 → ④ 입금·대출·비용 순서로 가져옵니다. 과거부터 이어진 계약은 '청구시작월'이 비어 있으면 이번 달부터 월세가 청구됩니다.

## 샘플 데이터 (테스트용)

부동산 5개(강남 사무실 빌딩·분당 오피스텔·마포 다가구·성수 물류창고·판교 상가), 호실 11개, 임차인 10명, 소유주 2명(개인·법인).
정상 입금 / 미납(1~30일·31~60일·90일 이상) / 공실 3개 / 계약 예정 / 만료 예정(30·60·90일) / 만료된 과거 계약 / 대출 4건(만기 임박 포함) / 12개월 비용이 들어 있습니다. 오늘 날짜 기준으로 만들어져 언제 넣어도 같은 상황이 재현됩니다.

## 내 컴퓨터에서 실행

```bash
cd rental-erp
cp .env.example .env.local   # DATABASE_URL, SETUP_PASSWORD 채우기
npm install
npm run migrate              # DB 표 만들기 (DATABASE_URL 필요: 터미널에서 export)
npm run dev                  # http://localhost:3000
```

| 명령 | 설명 |
|---|---|
| `npm test` | 계산 로직 테스트 (대출이자·자동 청구·입금 배분·미납 기간·손익·공실 손실·시뮬레이션·투자 분석·계산식) |
| `npm run typecheck` / `npm run lint` | 코드 검사 |
| `npm run build` | 배포용 빌드 (DB 주소가 있으면 표 자동 생성) |
