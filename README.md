# 렌트카 배차 관리

> 이 저장소에는 별도 프로그램인 **투자수익 장부**도 들어 있습니다 → [`invest-ledger/`](invest-ledger/README.md)

KKday 일정표를 올리면 보유 차량 수에 맞춰 **시간·거리 기준으로 자동 배차**하고(차량당 기본 4콜), 배차가 안 되는 건은 사유별로 따로 요약합니다.
기사 회원가입·신상정보 저장, 월별 **사업소득 원천징수(3.3%) 계산과 세무신고 자료 다운로드**까지 한 곳에서 처리합니다.

- 기술 스택: Next.js 16 (App Router) · Supabase (DB/인증) · Vercel 배포
- 주소 → 좌표 변환: 카카오 로컬 API (선택)

## 주요 기능

| 화면 | 기능 |
|---|---|
| 일정표 업로드 | KKday 엑셀(xlsx)·CSV 업로드, 컬럼 자동 인식(한/영/중), 매핑 수정, 미리보기, 예약번호 기준 덮어쓰기 |
| 배차 | 날짜·차량 선택 → 자동 배차, 차량별 동선(순번·공차 이동거리·여유시간), **배차 불가 요약**(사유별, 추가 필요 차량 수), 수동 차량 변경, 확정, CSV·카톡용 텍스트 |
| 차량 | 차량번호·차종·좌석 수·차고지 |
| 기사 | 기사 셀프 가입 → 신상정보 입력(주민번호·계좌는 암호화) → 관리자 승인·차량 연결 |
| 정산·세무 | 월별 기사별 지급액·소득세·지방소득세·차인지급액, 신고 기한, **간이지급명세서 자료 / 이체 목록 / 건별 내역** CSV |
| 기사 화면 | 확정된 내 배차(고객 전화 바로걸기), 월 예상 정산액 |

### 배차 방식

1. 좌석 수가 인원보다 적은 차량에는 배정하지 않습니다.
2. 앞 콜의 종료 시각(픽업 시각 + 소요시간)에 **이동시간 + 여유시간**을 더해도 다음 픽업에 늦지 않을 때만 같은 차량에 이어 붙입니다.
   - 이동시간 = 직선거리 × 도로보정계수 ÷ 평균속도 (좌표가 없으면 설정한 기본 이동시간)
   - 소요시간은 일정표의 소요시간 → 종료시간 → 상품명의 "4시간/8 hours" → 기본값 순서로 정합니다.
3. 공차 이동이 가장 적은 차량을 고르고, 빈 좌석이 많은 큰 차는 단체 예약용으로 남겨둡니다.
4. 여러 배정 순서로 풀어본 뒤 **배차 건수가 가장 많고 공차 이동이 가장 적은 결과**를 고릅니다. 한 번에 안 들어가는 건은 다른 차량의 콜을 옮겨(최대 2단계) 자리를 만듭니다.
5. 남은 건은 `픽업 시간 없음 / 인원 초과 / 모든 차량 콜 수 초과 / 시간 겹침·이동시간 부족`으로 분류하고, 모두 소화하려면 몇 대가 더 필요한지 추정합니다.

차량당 최대 콜 수, 여유시간, 평균속도 등은 **설정** 화면에서 바꿀 수 있습니다.

## 배포 방법

### 1. Supabase

1. [supabase.com](https://supabase.com)에서 새 프로젝트를 만듭니다 (리전: Northeast Asia (Seoul)).
2. **SQL Editor**에 `supabase/migrations/0001_init.sql` 내용을 붙여넣고 실행합니다.
3. **Authentication → URL Configuration**
   - Site URL: Vercel 배포 주소 (예: `https://rentcar-dispatch.vercel.app`)
   - Redirect URLs: `https://<배포주소>/auth/callback` 추가
4. **Project Settings → API**에서 `Project URL`, `anon` 키, `service_role` 키를 복사합니다.

### 2. 암호화 키 만들기

```bash
openssl rand -base64 32
```

나온 값을 `PII_ENCRYPTION_KEY`로 씁니다. **이 키를 잃어버리면 저장된 주민번호·계좌번호를 복호화할 수 없으니** 안전한 곳에 따로 보관하세요.

### 3. Vercel

1. [vercel.com](https://vercel.com) → **Add New Project** → 이 GitHub 저장소를 import합니다.
2. Environment Variables에 `.env.example`의 항목을 모두 넣습니다.

| 변수 | 값 |
|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | Supabase Project URL |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | anon 키 |
| `SUPABASE_SERVICE_ROLE_KEY` | service_role 키 (서버 전용) |
| `PII_ENCRYPTION_KEY` | 위에서 만든 키 |
| `KAKAO_REST_API_KEY` | (선택) 카카오 REST API 키 |

3. Deploy를 누릅니다.

### 4. 첫 관리자 계정

배포 주소의 `/signup`에서 **가장 먼저 가입한 계정이 자동으로 관리자**가 됩니다. 관리자 계정을 먼저 만든 뒤 기사님들께 가입 링크를 공유하세요.
관리자를 추가하려면 Supabase SQL Editor에서 실행합니다.

```sql
update profiles set role = 'admin' where email = '추가할@이메일';
```

### 5. (선택) 카카오 API: 거리 기반 배차

일정표에는 보통 좌표 없이 호텔명·주소만 있습니다. 카카오 키를 넣으면 배차할 때 주소와 장소명을 좌표로 바꿔(결과는 DB에 캐시) 실제 거리로 동선을 계산합니다.
[developers.kakao.com](https://developers.kakao.com) → 애플리케이션 추가 → **REST API 키**를 복사하고, 제품 설정에서 **카카오맵**을 활성화하세요.
키가 없어도 동작하지만, 그때는 콜 사이 이동시간을 설정의 "좌표 없을 때 이동시간"으로 가정합니다.

## 사용 순서

1. **차량** 등록 → **기사** 승인 후 차량 연결
2. **일정표 업로드**: KKday에서 받은 파일 업로드 → 컬럼 확인 → 저장
3. **배차**: 날짜 선택 → 자동 배차 → 배차 불가 요약 확인 → 필요하면 차량 변경 → **배차 확정** (확정해야 기사 화면에 보이고 정산에 반영됩니다)
4. 매월 초 **정산·세무**: 전월 자료 확인 → 간이지급명세서 자료로 홈택스 신고, 이체 목록으로 지급

## 세무 관련 안내

- 기사를 **프리랜서(인적용역 사업소득자)**로 보는 기준입니다. 소득세 3%와 지방소득세 0.3%를 계산하고, 10원 미만은 절사하며, 소득세 1,000원 미만은 소액부징수로 처리합니다.
- 원천세 신고·납부는 지급한 달의 다음 달 10일, 사업소득 간이지급명세서 제출은 다음 달 말일까지입니다.
- 간이지급명세서 CSV는 홈택스 작성에 필요한 항목(성명·주민번호·지급액·세액 등)을 정리한 자료이며, 홈택스 전자신고 전용 파일 형식은 아닙니다.
- 업종코드는 기본값 940909(기타자영업)입니다. 계약 형태에 따라 달라질 수 있으니 **첫 신고 전에 세무사와 확인**하세요.

## 개인정보 보호

- 주민등록번호·계좌번호는 서버에서 AES-256-GCM으로 암호화해 저장하고, 화면에는 마스킹해서 보여줍니다. 원문은 관리자만 볼 수 있습니다.
- 가입할 때 개인정보·고유식별정보 수집 동의(소득세법 시행령 제213조 근거)를 받고, 동의 시각을 저장합니다.
- Supabase RLS로 기사는 본인 정보와 확정된 본인 배차만 조회할 수 있습니다.

## 개발

```bash
cp .env.example .env.local   # 값 채우기
npm install
npm run dev        # http://localhost:3000
npm test           # 배차 알고리즘 · 파서 · 세금 계산 테스트
npm run typecheck && npm run lint && npm run build
```

`samples/kkday-sample.csv`는 업로드를 테스트할 수 있는 예시 일정표입니다.
